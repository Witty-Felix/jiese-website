# ADR 0003 — ima「戒色」KB 内按用户建文件夹

日期：2026-09-25
状态：已接受（实现细节待验证）→ **被 [ADR-0008](0008-two-level-folders-in-ima-kb.md) 部分取代**（2026-09-25 实测推翻下文的「无 create_folder 接口」结论，`IMA_USER_FOLDERS` 回退路径随之退休）
关联：ADR-0008

> 本文件正文按本仓库惯例**保留原貌、不改历史**。下文的「验证结论（2026-09-25 更新）」段建立在已被实测证伪的前提上，阅读时请以 ADR-0008 为准。

## 背景

一次打卡产生三个 ima 对象：1 条笔记 + 1 张图片 + 1 段录音。OpenAPI 只能分对象上传，无法内嵌。候选组织方式：按用户建文件夹 / 全部落根目录 / 再按月份分层。

## 决策

在 ima 共享知识库「戒色」下**为每个用户建一个文件夹**，该用户的笔记、图片、录音全部落入其文件夹：

- 笔记标题格式：`<昵称>的打卡 YYYY-MM-DD`。
- 图片/录音标题带昵称与日期，便于在文件夹内辨识。

## 实现路径与回退

- **优先路径**：验证 ima OpenAPI 是否提供建文件夹接口；若有，用户首次打卡时由 Function 自动建文件夹。
- **回退路径**（接口不存在时的既定方案）：由管理员在 ima 客户端手动预建用户文件夹，把「昵称 → folder_id」映射以 JSON 形式存在 Pages 环境变量（如 `IMA_USER_FOLDERS`）；新用户首次打卡时返回明确提示「请联系管理员开通文件夹」。
- 不采用按月份分层（v1 用不到；文件夹内靠标题日期排序已足够）。

## 后果

- 知识库结构清晰，逐人浏览打卡历史方便。
- 新用户接入多一步开通动作（回退路径下）——换取结构规整，值得。

## 验证结论（2026-09-25 更新）

- 官方 api.md（ima-skills-1.1.2.zip）确认：**OpenAPI 无 create_folder 接口**，文件夹只能在 ima 客户端创建。
- 回退路径自 v1 生效：`IMA_USER_FOLDERS` 环境变量（JSON：`{"昵称":"folder_id"}`）可选配置；未配置或无映射时落 KB 根目录。checkin.js 已内置该逻辑。
- 根目录的 folder_id = knowledge_base_id；`get_knowledge_list` 可传 folder_id 浏览子文件夹。
- v1 直接落根目录（当前无用户），标题已带昵称可辨识；日后人多再预建文件夹 + 补映射。
